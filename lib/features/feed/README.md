# Feed module

This branch owns the Feed tab. `module_entry.dart` connects the navigation shell to `presentation/feed_screen.dart`. The screen is an empty starting view; posts, uploads, recommendation ranking, and API calls are still to be built.

Planned endpoints: `GET /posts`, `POST /posts`, and `POST /uploads`. The advanced demonstration compares a personalized ranking based on content embeddings and interactions with a newest-first feed.
